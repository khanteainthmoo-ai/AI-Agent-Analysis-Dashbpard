# AI Agents & Customer Support Analytics | FP20 Challenge

## Project Overview

This project analyses customer support performance using Microsoft Power BI as part of the FP20 Challenge.

The objective is to evaluate the effectiveness of AI-driven customer support compared with traditional human support and hybrid AI-to-human support.

Using a dataset of 12,000 customer support tickets, the project investigates operational efficiency, customer satisfaction, resolution performance, SLA compliance and support costs to identify opportunities for improving customer service operations.

## Business Questions

The analysis aims to answer the following questions:

1. How does AI-only support compare with human-only support in resolving customer enquiries?
2. Which support journey delivers the highest customer satisfaction?
3. Which support journey is the most cost-efficient?
4. How does ticket complexity influence AI and human support performance?
5. What factors contribute to AI-to-human escalations?
6. Which support journeys experience higher repeat-contact rates?
7. How can organisations optimise AI adoption without compromising customer experience?

## Tools & Technologies

- **Microsoft Power BI** – Interactive dashboard development and data visualisation.
- **Power Query** – Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** – KPI calculations and analytical measures.
- **Data Modelling** – Relational data modelling and table relationships.
- **Exploratory Data Analysis (EDA)** – Identifying trends, patterns and performance differences.

## Dataset Overview

The dataset contains 12,000 customer support ticket records covering January 2025 to September 2026.

The analysis focuses on three support journeys:

| Support Journey | Description |
|---|---|
| AI Only | Customer enquiries handled entirely by AI |
| AI → Human | AI-assisted support with human escalation |
| Human Only | Customer enquiries handled entirely by human agents |

Key analytical dimensions include:

- Issue category and subcategory
- Customer profile and customer tier
- Support channel and support route
- Ticket complexity and priority
- Product information
- Ticket creation date
